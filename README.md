# Privacy Policy for Sprinkler Auto Connect
*Last updated: November 2026*

## 1. Data Collection and Usage
Sprinkler Auto Connect is an add-in designed for Autodesk® Revit®. We respect your privacy and are committed to protecting it.
* **No Personal Data Collected:** The application does not collect, monitor, store, or transmit any personally identifiable information (PII), project intellectual property, or user telemetry.
* **Local Settings Storage:** The app only saves user interface preferences (such as the last selected Pipe Type, Pipe System, and layout checkboxes) locally on your device in a plain text configuration file located at `%APPDATA%\SprinklerAutoConnect\settings.txt`. This data never leaves your computer.

## 2. Third-Party Sharing
We do not sell, trade, or share any user information with third parties. No analytics, tracking SDKs, or external advertising services are integrated into the application.

## 3. Data Retention and Deletion
Because no personal data is collected or stored on external servers, we retain zero user records. Any local configuration files can be permanently removed at any time by the user by deleting the `%APPDATA%\SprinklerAutoConnect` directory or uninstalling the add-in.

## 4. Revoking Consent and User Rights
Users have full control over the application. You can revoke consent and remove all traces of the add-in at any time simply by uninstalling it via **Windows Settings > Apps > Installed apps > Sprinkler Auto Connect**.
